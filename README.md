# Palindrome Checker

## Description

This Java console program checks whether a word or phrase is a palindrome. The program ignores capitalization, spaces, and punctuation when checking the text. It keeps only letters and numbers, reverses the cleaned text, and compares it to the original cleaned text.

## How to Run

1. Open the PalindromeChecker project in IntelliJ IDEA.
2. Open `Main.java`.
3. Click the green Run button.
4. Enter a word or phrase when prompted.
5. The program will display the original input, cleaned text, reversed text, and whether the input is a palindrome.

## Example Output

Palindrome Checker
------------------
Enter a word or phrase: A man, a plan, a canal: Panama!

Original input: A man, a plan, a canal: Panama!
Cleaned text: amanaplanacanalpanama
Reversed text: amanaplanacanalpanama
Result: This is a palindrome.
